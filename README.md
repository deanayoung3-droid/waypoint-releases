# Waypoint releases

Signed, notarised builds of [Waypoint](https://waypointapp.dev) for macOS.

This repository holds only the built `.dmg` files. It is public so the download
link and the in-app updater work without authentication — the source lives in a
private repository.

Every build is signed with a Developer ID certificate, notarised by Apple, and
carries an EdDSA signature the app verifies before installing an update.

**Requires macOS 14 or later. Works with iPhones on iOS 16 – 27.**
